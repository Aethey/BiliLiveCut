这是管理后台账号，与 Bilibili 账号登录无关。

在服务器运行以下命令，复制当前启动日志中最后一条初始化码。初始化码有效期为 30 分钟，使用后立即失效；过期可重启容器生成新码。

docker compose -f packaging/docker/compose.yaml logs --tail=100 app
忘记后台密码？

在运行 Docker 的服务器执行以下命令，再使用输出的一次性初始化码重新设置。此操作会退出所有浏览器，保留录制与业务数据。

docker compose -f packaging/docker/compose.yaml exec app python -m app.core.docker_auth reset

如已配置 ADMIN_PASSWORD，请修改 .env 后重建容器，网页不能覆盖部署密码。
